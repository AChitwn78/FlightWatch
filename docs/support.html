FlightWatch Support

FlightWatch is an installable web app for one-way and round-trip flight search and fare tracking. Demo search works immediately. Live results use a FlightWatch proxy you control and SerpApi.

Getting started

  1. Open FlightWatch in Safari, tap Share, and choose Add to Home Screen.
  2. Open the installed app and try a search in Demo mode.
  3. For live results, create a SerpApi account and deploy the supplied proxy. Enter both values under Settings and enable live results.
  4. Allow notifications if you want price-drop alerts while FlightWatch is checking.
  5. Search for an itinerary and choose Track flight or Track round trip.

On iPhone, this version checks tracked fares while FlightWatch is open. Use Check now after reopening it. Continuous monitoring while it is closed requires a hosted scheduler and Web Push service.

Common issues

Live search fails: Verify the proxy URL and SerpApi key in Settings. You can turn off live results to use sample data.

No notification appeared: Add FlightWatch to the iPhone Home Screen, enable notifications inside the installed app, then check Apple Settings for FlightWatch notification permissions.

A flight was not found during a refresh: Flight schedules and provider results can change. FlightWatch keeps the previous price and shows the refresh status; search again before booking.

Request limit reached: Check the current allowance and reset date in your SerpApi dashboard.

Contact and bug reports

Report a problem in the FlightWatch GitHub repository. Include your device model, iOS or macOS version, steps to reproduce, and a screenshot if helpful. Never include your SerpApi key.
